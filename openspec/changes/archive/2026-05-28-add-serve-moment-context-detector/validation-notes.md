### 误报/调参线索

- `arm_motion_peak_score` 在近端底线球员上很容易达到 1.0，因此不能单独主导置信度。
- `rally_after_score = 0` 的候选在 80-103s 形成密集簇，说明后续回合激活应进一步压低最终置信度，或在高置信输出中作为更强的门槛。
- `receiver_waiting_score = 1.0` 能说明对手等待，但不能替代发球后进入回合；等待 + 手臂峰值可能仍是练习动作或非回合启动。
- 当前 `min_gap_seconds = 6` 可以防止过密 marker，但对同一段等待中的多次手臂峰值仍会输出多个候选；后续可以增加“同一 ready 状态只取一个最优峰值”的合并逻辑。

### 后续建议

- 将 `rally_after_score` 为 0 的候选默认降到中低置信，除非有球/音频/人工标注证据。
- 增加 ready-state segment 聚合：先把连续底线准备窗口合并，再每段只取一个局部峰值。
- 针对 80-103s 这类候选导出 clips，作为 hard negatives 加入后续评估集。
