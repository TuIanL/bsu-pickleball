# api-access-control Specification

## Purpose
规范分析平台 API 的凭据校验、启动配置及契约文档暴露边界；保证本机演示通过同源代理访问 JSON 与原生媒体，服务端凭据不进入浏览器。

## Requirements
### Requirement: 所有 API 路由默认要求有效凭据

系统 SHALL 对**全部** API 路由施加统一的访问控制，任何业务请求在进入处理逻辑之前 MUST 通过凭据校验。当前状态是全站零鉴权：非 `get_db` 的依赖声明零命中，`APIKeyHeader` / `HTTPBearer` / `Authorization` 头解析 / 令牌校验函数在全仓均零命中，`main.py:66-95` 挂载 18 个路由无任何全局鉴权。这不只是「缺少一个功能」——它意味着任何能连到该端口的一方都可以创建分析任务、读取产物、触发取消、删除数据。

鉴权 MUST 施加在路由挂载层（覆盖全部已注册路由），MUST NOT 依赖逐个路由各自声明。加在单个路由上的鉴权会在新增路由时被无声遗漏，而新路由恰好是最容易写出危险操作的地方。

#### Scenario: 无凭据访问受保护路由

- **WHEN** 客户端在不提供任何凭据的情况下请求任一业务 API
- **THEN** 服务 SHALL 在进入该路由的处理逻辑之前拒绝请求
- **AND** SHALL NOT 泄漏该接口的存在之外的任何业务数据

#### Scenario: 有效凭据访问受保护路由

- **WHEN** 客户端提供与配置一致的凭据
- **THEN** 请求 SHALL 正常进入处理逻辑并返回该接口的正常响应

#### Scenario: 无效凭据访问受保护路由

- **WHEN** 客户端提供的凭据与配置不一致
- **THEN** 服务 SHALL 拒绝请求
- **AND** SHALL NOT 因为凭据错误而顺带泄漏内部错误细节或堆栈

#### Scenario: 新增路由自动受保护

- **WHEN** 开发者新增一个 API 路由
- **THEN** 该路由 SHALL 自动受到同一套访问控制约束
- **AND** MUST NOT 需要额外的显式声明才能被保护

#### Scenario: 恶意操作同样需要凭据

- **WHEN** 未通过鉴权的客户端尝试创建分析任务、取消运行中任务或删除数据
- **THEN** 这些操作 SHALL 全部被拒绝
- **AND** SHALL NOT 产生任何副作用（包括不创建任务记录、不改变任务状态、不落盘任何文件）

### Requirement: 凭据校验抗时序攻击

凭据比较 SHALL 使用常数时间比较，MUST NOT 使用会因提前返回而泄漏前缀长度的比较方式。请求头中的凭据 MUST 通过标准 `Authorization` 机制传递，MUST NOT 放在查询参数中——查询参数会被写入访问日志、浏览器历史与 `Referer` 头，等价于把凭据抄送给日志系统。

#### Scenario: 相同前缀的凭据被逐字节试探

- **WHEN** 攻击者用大量共享前缀的候选凭据依次试探
- **THEN** 每次请求的响应耗时 MUST NOT 随已匹配前缀的长度系统性变化
- **AND** 凭据正确性 SHALL 只由最终结果决定，MUST NOT 由响应时间侧信道泄露

#### Scenario: 凭据不出现在 URL 中

- **WHEN** 客户端携带凭据发起请求
- **THEN** 凭据 SHALL 只出现在请求头中
- **AND** 服务端访问日志与错误响应中 SHALL NOT 出现凭据原文

### Requirement: 无凭据配置时拒绝启动

当既未配置 API 凭据、又未显式声明豁免时，服务 SHALL **拒绝启动**并给出明确原因，MUST NOT 静默降级为「无保护运行」。本地开发场景通过一个显式的豁免开关放行，该开关 MUST 是有意识的动作（显式设置环境变量），MUST NOT 由「配置缺失」自动触发。

这是有意的破坏性变更。默认放行等于默认无保护：只要有人省略了配置，服务就会在所有人可达的网络上裸奔，而运维对此毫无提示。把失败模式从「静默无保护」改成「启动失败并说明原因」，是把安全从「依赖每个人配对」变成「依赖默认值正确」。

#### Scenario: 既无凭据也无豁免开关

- **WHEN** 启动服务时未配置 API 凭据，且未设置显式的鉴权豁免开关
- **THEN** 服务 SHALL 拒绝启动
- **AND** SHALL 输出说明缺失项与修复方式的信息，MUST NOT 继续进入监听状态

#### Scenario: 豁免开关下的本地开发

- **WHEN** 本地开发显式开启了鉴权豁免开关且未配置凭据
- **THEN** 服务 SHALL 正常启动
- **AND** SHALL 在日志中记录「本次运行未启用鉴权」这一事实，使运行者知道自己处于无保护状态

#### Scenario: 配置了凭据时豁免开关不生效

- **WHEN** 服务已配置有效凭据，同时残留了豁免开关
- **THEN** 鉴权 SHALL 仍然生效
- **AND** 豁免开关 MUST NOT 覆盖已配置的凭据

### Requirement: API 契约文档端点的暴露面可控

API 文档与机器可读契约端点（交互式文档、OpenAPI 契约、备注文档）在**远端部署**时 SHALL 不可访问。本项目当前 `main.py:58-63` 使用 FastAPI 默认值（全部开启），叠加全站零鉴权的后果是：任何可达的一方都可以拉取完整 API 契约，把「无鉴权」这一缺陷从人工发现变成自动化利用——攻击者可以直接枚举出创建任务、取消任务、删除数据、读取产物的全部端点与参数形状，无需任何侦察。

关闭 SHALL 依据部署形态判定（是否对外部署可达），MUST NOT 无条件关闭——本地开发与调试仍需要契约端点。

#### Scenario: 远端部署暴露文档端点

- **WHEN** 服务以可从本机网络之外访问的形态运行
- **THEN** 交互式文档、OpenAPI 契约与备注文档端点 SHALL 返回未找到
- **AND** SHALL NOT 在响应体中回显 API 结构

#### Scenario: 本地开发保留文档端点

- **WHEN** 服务以本地开发形态运行
- **THEN** API 契约文档 SHALL 可访问，以便开发者查阅接口
- **AND** 该形态 MUST NOT 被用于对外暴露的部署

#### Scenario: 静态资源与文档端点一并受控

- **WHEN** 远端部署关闭文档端点
- **THEN** 其他非业务暴露面（静态挂载目录等）SHALL 一并纳入同一暴露面判定，MUST NOT 留下等价的替代入口

### Requirement: 拒绝响应不得回显凭据

鉴权失败响应 SHALL 只表达「未通过凭据校验」这一事实，MUST NOT 回显请求中携带的凭据原文或其片段（包括部分掩码形式），MUST NOT 回显服务端配置的期望凭据。响应 SHALL 与请求中的凭据保持独立，使得攻击者无法通过响应内容逐步收敛出正确凭据。

#### Scenario: 错误凭据被拒绝

- **WHEN** 客户端提交错误的凭据并收到拒绝响应
- **THEN** 响应体 SHALL NOT 包含该凭据的任何片段
- **AND** SHALL NOT 包含服务端配置的期望凭据或其片段

#### Scenario: 缺少凭据的拒绝响应

- **WHEN** 客户端未提交凭据并收到拒绝响应
- **THEN** 响应 SHALL 说明需要凭据，但 SHALL NOT 描述凭据的格式、长度或前缀规则到足以缩小猜测范围的程度

#### Scenario: 服务端日志不记录凭据

- **WHEN** 服务记录一次鉴权失败
- **THEN** 日志 SHALL NOT 包含请求携带的凭据原文
- **AND** SHALL 保留足以定位来源的信息（时间、来源地址、目标端点）

### Requirement: 本机演示代理隔离凭据并覆盖原生媒体

本机演示 SHALL 默认仅绑定 loopback。浏览器 API、视频、图片和下载 SHALL 使用同源入口，服务端 SHALL 添加后端凭据。凭据 MUST NOT 被编译进前端产物或出现在 URL。开发服务器与构建后的本地预览 SHALL 保持同样行为。本机代理 MUST NOT 被用于局域网或公网部署。

#### Scenario: 原生视频通过同源入口读取
- **WHEN** 本机页面请求受保护的视频并发送 Range 请求
- **THEN** 代理 SHALL 添加凭据并保留 Range/206 语义
- **AND** 浏览器 SHALL 不需要持有后端凭据

#### Scenario: 跨来源页面或非本机连接访问代理
- **WHEN** 请求来自非 loopback 连接、非本机 Host 或跨来源浏览器页面
- **THEN** 代理 SHALL 在转发前拒绝请求
- **AND** SHALL 不产生后端业务副作用

#### Scenario: 构建后在本机预览
- **WHEN** 操作者以相同服务端凭据启动本地 preview
- **THEN** JSON 与原生媒体 SHALL 通过相同代理正常访问
- **AND** 静态构建产物 SHALL 不包含凭据
