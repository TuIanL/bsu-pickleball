## Requirements
### Requirement: 设备状态区

系统 SHALL 在采集控制台主界面仅显示当前采集方案使用的摄像头状态，不展示所有已注册摄像头列表。

#### Scenario: 单摄模式下展示设备状态
- **WHEN** 当前采集方案为单摄模式且已选择摄像头
- **THEN** 控制台右侧设备状态区展示该摄像头的名称、在线/离线状态、连接地址
- **AND** 提供「重新探测」和「更换摄像头」按钮
- **AND** 不展示其他已注册摄像头

#### Scenario: 双摄模式下展示设备状态
- **WHEN** 当前采集方案为双摄模式
- **THEN** 控制台设备状态区展示两张小卡，分别显示底线高机位和侧面机位的状态
- **AND** 每张卡显示对应摄像头的名称和在线状态
- **AND** 未选择摄像头的卡显示「未选择」状态并引导用户选择

#### Scenario: 未选择摄像头时的设备状态
- **WHEN** 采集控制台加载但尚未选择摄像头
- **THEN** 设备状态区显示「未选择摄像头」提示
- **AND** 提供「选择摄像头」按钮，点击后打开设备抽屉

### Requirement: 设备抽屉

系统 SHALL 提供设备抽屉面板，用于管理所有已注册摄像头。

#### Scenario: 打开设备抽屉
- **WHEN** 用户点击控制台中的「更换摄像头」或「选择摄像头」按钮
- **THEN** 系统从右侧滑出设备抽屉
- **AND** 抽屉标题显示「设备管理」
- **AND** 抽屉内容包含「已注册摄像头」列表、每个摄像头的名称/ID/协议/探测状态/操作按钮

#### Scenario: 在抽屉中选择摄像头
- **WHEN** 用户在设备抽屉中点击某个摄像头
- **THEN** 系统将该摄像头设为当前采集方案使用的摄像头
- **AND** 关闭抽屉
- **AND** 控制台设备状态区更新为新摄像头信息
- **AND** 预览区开始加载新摄像头的实时画面

#### Scenario: 在抽屉中注册新摄像头
- **WHEN** 用户在设备抽屉中点击「注册新摄像头」
- **THEN** 系统展开展示注册表单（camera_id、name、stream_url、protocol）
- **AND** 提交后调用 `createCamera` API
- **AND** 注册成功后刷新摄像头列表

#### Scenario: 在抽屉中探测摄像头
- **WHEN** 用户在设备抽屉中点击某摄像头的「探测」按钮
- **THEN** 系统调用 `probeCamera` API
- **AND** 显示探测结果（在线/离线、延迟、分辨率）

#### Scenario: 在抽屉中删除摄像头
- **WHEN** 用户在设备抽屉中点击某摄像头的「删除」按钮
- **THEN** 系统调用 `deleteCamera` API
- **AND** 删除成功后从列表中移除该摄像头
- **AND** 如果删除的摄像头是当前使用的，设备状态区回到「未选择」状态

#### Scenario: 关闭设备抽屉
- **WHEN** 用户点击抽屉外部遮罩或关闭按钮
- **THEN** 设备抽屉滑出关闭
- **AND** 当前设备选择不受影响

### Requirement: 按机位槽位选择摄像头

系统 SHALL 支持在设备抽屉中为指定机位槽位（`cam_1` 或 `cam_2`）选择摄像头。

#### Scenario: 双摄模式下展示设备状态
- **WHEN** 当前采集方案为双摄模式
- **THEN** 控制台设备状态区展示两张槽位卡（SlotCard），分别显示底线机位 A（`cam_1`）和底线机位 B（`cam_2`）
- **AND** 每张卡展示对应摄像头的名称、在线状态（探测后）、探测和更换按钮
- **AND** 未分配摄像头的槽位显示「未分配摄像头」提示

#### Scenario: 为底线机位 A 选择摄像头
- **WHEN** 用户从双摄控制台的底线机位 A 槽位打开设备抽屉并选择摄像头
- **THEN** 系统将该摄像头设置为 `cam_1`
- **AND** 系统关闭设备抽屉
- **AND** 双摄控制台更新底线机位 A 状态

#### Scenario: 为底线机位 B 选择摄像头
- **WHEN** 用户从双摄控制台的底线机位 B 槽位打开设备抽屉并选择摄像头
- **THEN** 系统将该摄像头设置为 `cam_2`
- **AND** 系统关闭设备抽屉
- **AND** 双摄控制台更新底线机位 B 状态

#### Scenario: 防止重复选择同一摄像头
- **WHEN** 用户尝试把已经用于另一个机位槽位的摄像头选择到当前槽位
- **THEN** 系统 MUST 阻止该选择
- **AND** 系统不得让 `cam_1` 和 `cam_2` 保存同一个摄像头 ID

### Requirement: 双摄槽位选择持久化

系统 SHALL 在当前浏览器会话中保留双摄机位选择。

#### Scenario: 刷新双摄控制台
- **WHEN** 用户已经为双摄采集任务选择了两个机位并刷新页面
- **THEN** 系统通过 sessionStorage 恢复该 Field Session 对应的 `cam_1` 和 `cam_2` 选择
- **AND** 系统继续显示对应摄像头的设备状态
