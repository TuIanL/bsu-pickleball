# delete-result-toast Specification

## Purpose

定义删除操作结果提示的轻量浮动 toast 组件契约：右下角固定定位、不占版面；全部成功时自动 3 秒消失且不显示倒计时；存在受阻（受保护/未找到/失败）时需手动关闭；文案仅一行（删除数与受阻简述）。

## Requirements

### Requirement: 删除结果以浮动 toast 展示

删除结果 SHALL 以右下角固定定位的紧凑 toast 呈现，不占用或挤压页面内容区；每页同时最多显示一个删除 toast，新的删除结果替换旧的。

#### Scenario: 删除成功后显示右下角 toast

- **WHEN** 一次删除动作完成
- **THEN** 页面右下角显示一个紧凑 toast（`fixed bottom-4 right-4`），内容仅一行，页面列表内容不被挤动

#### Scenario: 全部成功自动消失且无倒计时

- **WHEN** 删除的全部项目均成功（无受保护/未找到/失败）
- **THEN** toast 显示绿色样式，3 秒后自动消失，且不展示倒计时或进度条

#### Scenario: 有受阻时需手动关闭

- **WHEN** 删除结果存在受保护、未找到或失败项
- **THEN** toast 显示琥珀色样式并带 × 关闭按钮，不自动消失，等待用户手动关闭

#### Scenario: 新删除动作替换旧 toast

- **WHEN** 一个删除 toast 正在显示时用户再次执行删除
- **THEN** 新的删除结果替换当前 toast，且自动消失定时器重置

### Requirement: 文案仅一行，包含删除数与受阻简述

toast 文案 SHALL 保持单行：全部成功时仅显示"已删除 N 个任务"（含单位词）；存在受阻时显示删除数与非零的受阻原因简述，不显示零计数项。

#### Scenario: 全部成功文案

- **WHEN** 删除全部成功
- **THEN** toast 文案为 `已删除 N 个任务` 这类单行表述

#### Scenario: 受阻文案只含非零项

- **WHEN** 删除存在受阻项
- **THEN** toast 文案为 `已删除 N 个，M 个未删除` 并附非零的受阻原因（如 `受保护 X · 未找到 Y · 失败 Z`），零计数的原因不出现
