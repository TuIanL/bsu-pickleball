# 现场展示模式

## 现场操作

1. 在“新建采集任务”中选择“现场展示模式”。系统会自动选择双摄方案；如果切回单摄，模式会恢复为标准模式。
2. 在采集控制台完成两路摄像头短录测试并开始录制。
3. 录制成功后，点击“展示屏”，在另一台显示器或独立浏览器窗口打开页面。
4. 展示屏显示两路带人体框、track ID 和置信度的实时画面。球点和短轨迹只有在球模型和现场配置可用时出现。
5. 点击操作屏的停止按钮结束录制。展示旁路会独立关闭，原始双摄分段继续按既有流程收尾、合并和进入完整分析。

## 模式差异

- 标准模式不启动展示 worker、不加载展示模型，普通预览和录制行为保持不变。
- 展示模式只允许双摄。实时画面是现场反馈，不是正式分析输入。
- 实时球轨迹只表示当前视角的观测短轨迹，不代表录制后的清洗、弹跳识别或双摄融合结果。

## 故障回退

- 人体模型不可用时，展示状态会显示降级原因，画面可回退到普通预览；原始录制继续。
- 球模型不可用或当前没有有效候选时，不绘制猜测的连续球路，人体框和录制继续。
- 一路展示流断开时，另一路和两路原始录制不受影响。
- 关闭、刷新或离开展示屏不会停止录制；只有操作屏上的明确停止/取消操作会改变录制状态。

## 现场默认配置

默认实时处理宽度为 960 像素、目标推理帧率为 8 FPS、JPEG 质量为 78，球检测默认关闭。目标电脑和真实双摄压测后，可通过 `PICKLEBALL_SHOWCASE_PROCESSING_WIDTH`、`PICKLEBALL_SHOWCASE_INFERENCE_FPS`、`PICKLEBALL_SHOWCASE_JPEG_QUALITY` 和 `PICKLEBALL_SHOWCASE_BALL_ENABLED` 调整。
