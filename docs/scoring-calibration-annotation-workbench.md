# 评分校准标注工作台

评分校准标注工作台用于把你们自己的比赛视频转换成可审计的人工事实，供后续指标校验和评分校准使用。

## 使用前提

- 视频必须已经注册到系统的 `CaptureTake`，工作台不直接读取 PB Vision 分享链接。
- PB Vision 的 JSON/Excel 可以作为外部对照，但不会自动成为人工真值。
- 当前第一版标注发球、接发、入界结果、机会状态和可观察落点区域，不生成六维技能分数或 Overall 分数。

## 打开工作台

从比赛库中打开一个已注册的录制素材，在素材详情标题下点击“评分校准”；也可以从“视频回放”或“片段管理”页面进入，或直接打开：

```text
/capture/{field_session_id}/takes/{capture_take_id}/scoring-calibration
```

第一次进入时创建一个 draft 标注包。工作台默认进入“快速校准”：从有效 rally 中均匀抽样最多 12 个回合，播放器会定位到当前回合，并显示已处理、待处理和跳过进度。可以切换“全部回合”，但第一批校准不要求重做整场比赛。

## 第一批推荐流程

1. 先播放当前回合的小窗口，确认是否看得到发球和接发。
2. 直接点击“发球入界”“发球失败”“接发入界”或“接发不可观察”；这些按钮会自动填充回合、事件时间和证据窗口。
3. 证据不足时使用“接发不可观察”，它会保存为 `unobservable + unknown`，不会被当成接发失败；看不清整个回合时使用“跳过当前回合”。
4. 快速事实保存后会进入下一个待处理回合。需要击球人、落点区域、置信度或备注时，再打开“补充字段”。
5. 抽样完成后仍按原流程标记 `reviewed` 并锁定 Gold Set。

候选区会优先显示当前回合附近的已落盘分析候选。如果外置分析目录不存在，或候选的视频 ID 与当前 CaptureTake 不匹配，页面会显示原因，但不影响人工快捷校准。

## 详细标注流程

1. 播放、暂停或逐帧查看视频；可以拖动播放头定位到击球证据。
2. 点击算法候选会自动填入时间窗；候选只是定位建议，必须人工确认后保存。
3. 没有候选时点击“新建”，直接在当前视频位置创建人工条目。
4. 填写阶段、机会状态、结果、落点状态/区域、击球人和备注。
5. `unobservable` 表示证据不足，不等于失败；发球无效时，接发机会可以使用 `not_applicable`。
6. 使用“保存并下一条”连续处理未复核事件。
7. 校验没有阻塞错误后，先标记 `reviewed`，再点击“锁定 Gold Set”。

## revision 与 Gold Set

- `draft`：可以继续编辑，不用于评分校准。
- `reviewed`：通过结构校验，仍可继续修正。
- `locked`：生成不可变的 `scoring-calibration-annotation.v1` Gold Set。
- 已锁定版本不能原地修改；需要点击“创建修订”生成新的 draft revision。

下游可以通过以下接口查询状态和读取锁定事实：

```text
GET /api/capture-takes/{capture_take_id}/scoring-calibration/gold-set-status
GET /api/scoring-calibration/packages/{revision_id}/gold-set
```

没有 locked Gold Set 时，状态接口会返回 `not_ready` 和“尚无可用校准真值”，现有报告不会因此虚构评分。

## 与机器学习的关系

这个工作台第一阶段不训练模型。人工标注形成 Gold Set，之后可以用来计算候选算法的漏检率、误检率和语义准确率；当样本积累到足够规模后，才考虑训练或微调击球、结果和落点识别模型。
