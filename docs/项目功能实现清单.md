## 十二、关键技术栈

- **前端**：React 19 + Vite 7 + TypeScript + Tailwind CSS 4 + D3.js（热力图/散点图）+ lucide-react
- **后端**：Python 3.13 + FastAPI + Uvicorn + SQLAlchemy 2（SQLite）+ Pydantic 2
- **视觉算法**：OpenCV + YOLO11（人体检测）+ RTMPose26（26 关键点姿态）+ 单应性矩阵（球场投影）；球检测 / 轨迹为可插拔适配器（模型缺失时优雅降级）
- **采集**：FFmpeg 双路 `.ts` 分段同步录制 + 合并；RTSP 摄像头探测 / 预览
- **数据链路**：Field Session → Capture Take → Timeline Event → Segment → Analysis Job → Report（一次真实球场活动成为可持续使用的数据对象）

### ✅ 已在代码中真实落地（可运行 / 已测试）
- 视频上传、流播放、PTS 时间轴；分析任务全生命周期（队列 / Worker / 状态机 / 幂等 / 取消 / 超时 / 僵尸恢复 / 资源限制）。

- 球员 YOLO11 检测 + 多目标跟踪 + 脚点估计与球场投影；主球员 / 单双打选择。
- 双摄同步录制、双摄轨迹融合与全局身份名册（global roster）、跨视角恢复诊断、双摄实时展示大屏。
- RTMPose26 姿态（单摄产出骨架叠加）。
- 匹克球专项指标：移动距离、速度、厨房区停留、双打间距、位置热力图 / 散点图、结构化可视化（**真实计算**）。

- Vidat 本地标注工作台；前端分析 / 报告 / 视觉工作台 / 多视角可观测性 / 采集全链路 UI；摄像头登记 / 探测 / 预览。
