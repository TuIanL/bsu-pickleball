## 打开与停止

在项目根目录双击 `start-pickleball.cmd`，打开 <http://127.0.0.1:5173>。停止时双击 `stop-pickleball.cmd`。

终端等价命令：

```powershell
cd D:\匹克球\bsu-pickleball
npm run app:start:windows
npm run app:stop:windows
```

后端文档：<http://127.0.0.1:8000/docs>。

配置在被 Git 忽略的 `.env.local`。API token 随机生成，只由本地服务端使用；浏览器经 `/__analysis_api` 访问 API。不要把 token 改成 `VITE_*` 变量，也不要提交环境文件。

日志：`.runtime/logs/backend.log`、`analysis-worker.log`、`frontend.log`。

```powershell
.venv\Scripts\python.exe scripts\windows_runtime.py status
```

API 和前端自动重载。改算法后要停止并重新启动 Worker；它不会跟随 API 自动重载。

## Windows 适配修改

- 新增 Windows 启停脚本、进程身份记录与 VS Code 调试配置。
- 三处临时文件关闭后才替换/删除，修复 PTS sidecar、同步准备、双摄调试轨迹写入。
- 录制进程在 Windows 不再调用不存在的 `os.getpgid`。
- Vidat 在没有符号链接权限时使用 NTFS 硬链接，跨盘时复制。
- Windows 并发刷新任务 JSON 时，暂时文件共享冲突会进行有界重试，避免中断 Worker 心跳。
- 前端检查和文件监视排除本地运行时、虚拟环境及生成数据。
- 后台 Vite 关闭交互式标准输入退出行为，防止双击启动后网页服务自动退出。
- OpenCV 图像读写兼容中文 Windows 路径，覆盖标定预览、姿态检查、抽帧和可视化图片保存。

这些 Windows 适配已在 2026-10-26 保存为独立本地提交并与线上代码合并，尚未推送 GitHub。
