# 片段管理交互说明

## 片段回放

- 右侧片段行或片段标签单击后，播放器定位到该片段的有效起点并自动播放。
- 播放范围使用 `effective_start_ms` / `effective_end_ms`；播放到有效终点后自动暂停，当前片段保持高亮。
- 播放过程中，播放器时间、时间线红色播放头、当前片段高亮会同步更新。
- 播放器底部进度条支持拖拽 seek；时间线红色播放头也支持拖拽 seek，两者都不会自动修改片段边界。
- 标签双击进入编辑；复选框、拆分、归档和合并按钮不会触发片段播放。
- 时间线片段块单击只定位到起点并暂停，时间线空白区域单击只执行 seek，不会自动播放。

## 边界编辑

- 时间线左右边界手柄拖动期间只更新本地预览，不会连续发送请求。
- 释放手柄时只提交一次 `corrected_start_ms` / `corrected_end_ms`，并携带拖动开始时的 `edit_version`。
- 起点、终点会被限制在媒体范围内，且片段时长不能小于 0.5 秒；保存中不能重复编辑同一片段。
- 保存失败时重新读取片段数据，恢复服务端边界；版本冲突使用 409 语义提示并要求重新加载。
- 异常边界（结束不晚于起点、负数或过短）会显示错误提示，并禁止再次拖拽保存。

## 关键事件与分析

- 时间线事件标记是只读展示。seek、播放和片段边界拖动都不会修改 `SessionTimelineEvent`。
- 边界拖动只修改片段的有效范围和编辑操作记录；后续分析批次使用修正后的有效范围。
- 因此，“拖拽时间线”改变的是片段选取范围，不是比赛关键事件本身。
